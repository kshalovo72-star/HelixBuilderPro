# HelixBuilderPro 3D Module

## Planned features

- Interactive 3D helix antenna model
- Finger rotation and pinch zoom
- Animated assembly mode:
  - wire winding animation
  - 12 turns appearing step by step
  - reflector installation
  - feed point connection
- Parameter driven model generation:
  - number of turns
  - coil diameter
  - pitch
  - wire diameter

## 3D printing support

The application will prepare printable files:

- STL export for holders and assembly parts
- 3MF export with printer metadata
- OBJ/GLB preview model
- Android share action to send files to slicer applications

## Future modules

- Built-in slicer presets
- Material selection (PLA/PETG/ABS)
- Print size preview
- Automatic support recommendations
