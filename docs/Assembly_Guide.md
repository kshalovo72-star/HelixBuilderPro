# Подробная инструкция сборки Helix 4990 12 витков

## 1. Подготовка деталей
Подготовить:
- провод для спирали;
- каркас нужного диаметра;
- отражатель;
- разъём питания;
- измерительное оборудование для проверки.

## 2. Формирование спирали
1. Закрепить начало провода.
2. Выполнить намотку 12 витков.
3. Проверить одинаковый шаг между витками.
4. Проверить отсутствие деформаций.

## 3. Установка отражателя
- установить спираль относительно отражателя;
- проверить соосность конструкции;
- закрепить механические элементы.

## 4. Подключение
- установить точку питания;
- проверить надёжность соединений;
- исключить механические напряжения кабеля.

## 5. 3D-печать
Приложение будет создавать:
- STL детали каркаса;
- держатели спирали;
- шаблон намотки;
- сборочный чертёж.

## 6. Интерактивный режим приложения
Планируется:
- пошаговая анимация сборки;
- подсветка деталей на 3D-модели;
- режим обучения для новичков.
