# HelixBuilderPro — Калькулятор спиральной антенны

## Назначение
Модуль рассчитывает основные параметры 12-витковой спиральной антенны.

## Входные параметры
- Частота работы (МГц)
- Количество витков
- Диаметр спирали
- Диаметр провода
- Шаг витка
- Диаметр отражателя

## Расчётные параметры
Приложение показывает:
- длину одного витка;
- общую длину провода;
- длину спирали;
- рекомендуемый шаг;
- размеры 3D-модели для печати.

## Пример профиля
Антенна: Helix 4990
- Витки: 12
- Режим: правосторонняя спираль
- Модель: параметрическая 3D

## Важно
Финальная настройка антенны выполняется измерением КСВ после изготовления.
