# HelixBuilderPro Calculator

## Возможности калькулятора

Параметры:
- рабочая частота;
- количество витков (по умолчанию 12);
- диаметр спирали;
- диаметр провода;
- шаг витка;
- длина намотки;
- размер отражателя.

## Расчётный модуль

Калькулятор должен автоматически формировать:
- геометрию спирали;
- длину провода;
- расстояние между витками;
- параметры 3D модели;
- данные для экспорта STL/3MF.

## Подробная инструкция

### Шаг 1. Подготовка
- выбрать частоту работы;
- проверить размеры деталей;
- подготовить провод и каркас.

### Шаг 2. Формирование спирали
- установить количество витков;
- выполнить равномерную намотку;
- проверить шаг между витками.

### Шаг 3. Сборка
- закрепить спираль;
- установить отражатель;
- подключить точку питания.

### Шаг 4. Проверка
- выполнить измерения;
- проверить соответствие расчётной модели.

## 3D режим

Планируется:
- генерация модели по параметрам;
- анимация сборки;
- экспорт STL и 3MF для печати.
